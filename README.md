# Basic-cs-MVC

mvc setup 

make sure you already have C# Dev Kit

## step by step

```
ctrl + shift + p 

type ".NET: New Project"

click on "Console App"

click create project

name: <yanjimtee>
```

```

```



to run

```
cd MvcConsoleApp

dotnet run
```
